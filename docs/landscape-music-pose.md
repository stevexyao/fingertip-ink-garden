# 山水、远近、转腕与国风器乐

## 可直接使用的交互

首次舒掌停稳约500ms，每只手建立独立的自然大小与朝向基准。手靠近镜头，花朵放大；远离缩小，范围0.65–1.8倍并受画布安全尺寸上限约束。张合只控制花瓣开合，不因靠近自动变成盛放。每手主花头绕食指花心旋转，枝叶仅轻摆；转过±180°时采用最短角差平滑。

四种程序绘制的背景为云山远岫、江南水乡、竹林听风、荷塘月色，默认江南水乡。宣纸和风景只在切景／实际尺寸变化时重新绘制，中心留白供花朵使用。水纹随当前花心扩散，无历史绘画轨迹，数量有上限。

音乐需点击开启，由浏览器本机Web Audio进行程序作曲与合成。当前采用两条独立声部：风景拥有带长音、气口与分句的主旋律，花型在另一条声部持续应答。切花只更换应答音色，保留风景乐句及已在发声的长音；切景更换主题旋律、节拍与配器。

| 风景 | 节拍与速度 | 主旋律音色 |
| --- | --- | --- |
| 云山远岫 | 4/4拍，56 BPM | 远山长箫 |
| 江南水乡 | 6/8拍，68 BPM | 水乡筝箫 |
| 竹林听风 | 4/4拍，74 BPM | 竹间清笛 |
| 荷塘月色 | 4/4拍，50 BPM | 月下低埙 |

江南水乡按每拍三细分安排6/8节拍与伴奏落点。其余三景采用4/4拍，各自具有不同的旋律、呼吸与伴奏密度。花型应答对应牡丹暖弦、荷花箫声、梅花泛音、菊花柔筝、兰花清笛；两个固定槽位保序，失检不挤位，静止或无手时保留最近音色配置，尚未入镜的点选指令也会更新音色。

风景与花型各保留一套活动乐器组和最多一套淡出乐器组，两轨合计最多四套rack。切花淡变约0.78秒，切景约0.85秒；快速连续切换会回收更旧的淡出组。全局用户音量同时作用所有乐器组。摆动增加节拍内装饰音，开合调节花型声部的音色，位置产生轻微立体声变化；500ms无新手部结果时不再增加手势装饰音。

默认音量30%，可静音和恢复；静音时乐曲继续，暂停后再开启从当前主题开头播放。沉浸模式保留音乐控件。切换配置不会自动启播或改动音量，后台暂停。音乐合成不使用麦克风；[声控存画](./voice-capture.md)拥有独立开关与授权。

## 数据与接口

`FlowerState`增加可选`scale`、`rotation`、`motion`，缺省1／0／0，原有缩略图、演示与选花调用保持兼容。`HandPoseTracker`仅由新捕获帧推进，按手ID保管基准与平滑状态；坐标、悬停花牌及光标不随缩放旋转。短暂失检沿用基准，超过跟踪保留时间后的新ID重新校准；严重侧掌和异常坐标保持上一有效姿态。

`InkGardenRenderer.setLandscape(type)`切换缓存风景。`GardenMusic`提供`start`／`pause`／`setScene`／`setFlowers`／`setVolume`／`update`／`flowerSelected`／`dispose`；`setFlowers`最多接收两个按槽位排序的花型，重复配置幂等，空数组保留最近配置。页面先同步持续音色，再发柔和的选花确认音。`MusicStatus`给出当前风景、主奏与花型音色说明。

450ms前瞻调度减少识别计算对节拍的影响，暂停停止未来声音。`renderGardenMusicPreview(seconds, { scene, flowers, volume })`可离线渲染同一套乐谱与合成器，供试听和信号检查。主旋律与应答分别调度，切花不重启风景播放位置；新主题从自身乐句开始。

手动存画和声控共用`renderer.exportPng()`，截取后显示PNG缩略图与可点击下载入口。导出只含山水、花卉与水纹，音频、摄像头和界面控件不包含其中。

## 验证边界

本地全量112项单元测试通过，覆盖手部、停留、姿态、音乐与声控状态。音乐页面检查使用真实AudioContext DSP和测试专用静音输出，检查信号、静音、恢复、暂停、配置切换及资源上限；长句乐谱、6/8分组和切花不重启风景轨道另有结构回归。结构与信号检查不能证明真人听感或演奏自然度，物理扬声器听感仍需试听。

模型另对官方手图实际像素进行缩放、旋转后推理。此检查仍属于图片输入，未验证真人摄像头、真实景深或各款手机表现。声控18项页面检查使用模拟SpeechRecognition事件和真实PNG下载，尚无真人麦克风实测。

原始模型、页面和离线音频记录位于内部开发目录`output/playwright/`。本文说明当前源码与本地验证，本次改动的部署状态另行确认。
