# 指尖停留选花

## 使用

开启摄像头后，画布底部出现牡丹、荷花、梅花、菊花、兰花五张花牌。将食指处标记“一”或“二”的光标移到花牌，停留约800毫秒，进度环走满后切换对应的花。双手独立，不依赖侧栏当前选中哪一朵。

鼠标、触摸和键盘仍可选择：先点第一朵／第二朵，再点花牌或底部花库。当前选中的槽位会显示在花牌栏。手动选择取消该手尚未完成的停留，移开当时目标后才能再次触发它。

## 触发边界

- 连续命中同一张花牌满800ms，至少三次不同采集时间的有效识别，才发出一次选择。
- 仅新的模型结果推进计时，动画重绘不推进。重复或回退帧忽略。
- 采集或接收间隔超过400ms，重新开始未完成的计时。明确丢手、移出目标、改变目标会清除进度。
- 已完成或人工取消后，同一目标锁定至实际离开；识别停顿不会解除人工选择的保护锁。有效无手或新会话会清除锁。
- 当前花型只高亮，不重复发出事件。保持不动不会轮换花型。
- 关闭摄像头、切到赏花体验、切后台及调整画布尺寸会清空悬停状态。

## 实现

`DwellFlowerSelector.update(hands, targets, capturedAt, receivedAt)`接收本次有效手部ID、镜像指尖、当前花型、归一化花牌矩形和双时钟；返回每手进度与一次性选花事件。`cancel(id)`取消并保护该手当前目标，`clear()`开始新会话。

`HandGestureTracker`保留手部身份、张合、位置平滑、淡出和花型记忆，移除自动挥手切花。悬停结果使用相同ID调用`setFlower`，不会把第一朵的选择写给第二朵；淡出保留手不参与新一帧悬停。

花牌与光标位于画布的HTML叠层，坐标只镜像一次，导出的国画PNG不包含选花界面和摄像头。沉浸模式保留选花栏；摄像头小窗放在上方，手机花牌点击区域至少44×44像素。

## 验证边界

单元测试覆盖800ms、三帧、5fps、乱序、断档、无手、双手、取消与锁；浏览器回归使用官方手图识别出的真实21点形状，再控制位置来重复验证页面链路。真实模型的图片／视频流推理另行检查。

以上不等于真人摄像头实测；真实手机设备及不同光线仍需试用。若光标难以指向目标，请保持完整手掌入镜并调整距离，或直接使用点击／触摸选花。
